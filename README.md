# Number Guessing Game 🎯

A simple and interactive **Number Guessing Game** where the player tries to guess a randomly generated number within a specified range.The game provides hints after each guess,helping the player determine whether their guess is too high or too low.

Features

* 🎲 Random number generation
* 🔢 User-friendly guessing system
* 💡 Hints for each incorrect guess
* 🏆 Tracks the number of attempts
* 🔄 Option to play again

How It Works

The computer generates a random number,and the player keeps entering guesses until they find the correct number.After every guess,the game gives a hint to make the next guess easier.

A fun beginner friendly project to practice programming logic, loops, conditionals, user input, and random number generation.
